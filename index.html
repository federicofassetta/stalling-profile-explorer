Loading your data

The explorer reads two files written by R/export_for_web.R (in this repository). Run it in the R session where you built cov_long; it writes them to data/local/.

  • sequences.tsv.gz — one row per sequence: seq.id plus metadata (seq, motif.type, motif.length, periodicity, STR.motif.ssDNA, pred.struct…). Any extra column you add becomes a filter automatically.
  • profiles.tsv.gz — one row per sequence and sample: seq.id, sample, then the read count at each position in columns p1 … p150.
Drop both files here, anywhere on the page, or click to choose them.
.tsv, .csv or gzip-compressed. Nothing leaves your computer.

Two other layouts also load: a long table with seq.id, pos, depth and sample (e.g. cov_long written with fwrite), and the older format with one *.depth column per sample.

Automatic loading

If you open the site through a local web server, it loads data/local/manifest.json on start. In a terminal:

cd ~/Projects/stalling-profile-explorer
python3 -m http.server 8000
# then open http://localhost:8000

data/local/ is excluded from git, so your unpublished data is never pushed to GitHub. The public site shows the demo data until you load your own files.

What the numbers mean

Distance from STR start
dist = STR start − pos, with the STR start at position 100 by default, exactly as in the R script. 0 is the first nucleotide of the STR.
Normalisation
÷ maximum divides each sequence-by-sample profile by its own highest position, so every profile peaks at 1 (your norm column). ÷ total turns each profile into the fraction of its reads ending at each position, which keeps the relative height of peaks comparable between sequences. Raw shows read counts. Profiles with no reads are left out of every average.
Stall window
A range of distances you choose in the sidebar. For each sequence and sample, the window fraction is the reads ending inside the window divided by all reads for that profile. It uses raw counts, so it does not change with the normalisation setting. Δ is the window fraction in sample B minus sample A: positive means more stalling in the window in B.
Peak
The distance of the single highest position in the profile.
Min. total reads
Profiles with fewer reads than this are excluded from averages, heatmaps and metrics. Low-coverage profiles are noisy, so raising this to 20–50 often sharpens the averages.
